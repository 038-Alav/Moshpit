# Moshpit UI/UX Blueprint v0.1

Este paquete contiene el UI/UX Blueprint y ocho wireframes (desktop + mobile) para revisión previa a cualquier implementación.

- `MOSHPIT_UI_UX_BLUEPRINT_v0.1.md`: especificación de navegación, diseño, pantallas, estados, componentes y alcance por demo.
- `wireframes/index.html`: galería navegable.
- `wireframes/*.svg`: wireframes editables en formato vectorial.

No incluye cambios de código ni introduce dependencias en el proyecto actual.
